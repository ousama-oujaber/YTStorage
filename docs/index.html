Engineered for Unforgiving Clouds

Modern streaming CDNs utilize aggressive lossy re-encoding. YTDisk defeats them through mathematical guarantees.

4K Nearest-Neighbor Upscaling

By rendering monochrome frames at 1080p and scaling to 3840×2160 via strict nearest-neighbor sampling, YouTube is forced to encode with top-tier VP9/AV1 bitrates, preventing block bleeding.

Matrix Temporal Interleaving

Codewords are transposed before rasterization ($M^T$). Contiguous video compression glitches affect only isolated bytes across hundreds of codewords, fully correctable by Reed–Solomon.

Scrypt + AES-256-GCM

State-of-the-art zero-knowledge cryptography with 128-bit authentication tags and ASIC-resistant Scrypt key derivation ($N=32768, r=8, p=1$). Passwords are never stored on disk.

Instant Header Inspector

Inspect container version, original filename, byte length, and encryption flags from the 30-frame optical header in <150 ms without downloading or decoding the gigabyte video payload.

Native Cloud Ingestion

Integrated streaming download manager for YouTube (via embedded yt-dlp) and Google Drive (resumable range chunks) with automatic container recognition and on-the-fly decoding.

100% Python Interop

Strict bidirectional compatibility with the legacy Python reference script. Videos generated by Python decode cleanly in Rust, and Rust videos decode cleanly in Python.
